Como interpretar

O modelo retorna uma classe entre 0 e 3. O resultado é uma indicação para apoiar a inspeção, não substitui avaliação técnica.

Classes do modelo

0Normal
1Desgaste de rolamento
2Desbalanceamento do rotor
3Cavitação / superaquecimento
Preencha os valores e clique em analisar.

Selecione a peça que deseja verificar.
ⓘPara uma comparação melhor: use fotos com ângulo, distância e enquadramento parecidos. Arquivos JPG, PNG ou WEBP de até 10 MB. Diferença acima de 8% é indicada como possível problema.
A visão computacional continua disponível mesmo com a API de sensores desligada.

O limite de 8% é uma regra inicial por comparação de pixels. Confirme o resultado visualmente; hotspots por cor não medem temperatura real.
